# Agent Plugins

Portable, independently packageable plugins for the open [Agent Plugins standard](https://agent-plugins.org/).

## Plugins

| Plugin | Status | Capabilities |
|---|---|---|
| [Office](./plugins/office/) | Alpha | PPTX creation, import, editing, preview, validation, search, and export |
| [Rostra](./plugins/rostra/) | Draft (design) | Unified sovereign search + research data layer (web, news, markets, social, GitHub, YouTube) via the Rostra MCP endpoint — declaration + skills plugin |

Each `plugins/<name>/` directory is a self-contained Agent Plugin package. See [CONTRIBUTING.md](./CONTRIBUTING.md) and [development documentation](./docs/development.md) to contribute.
