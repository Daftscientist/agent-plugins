# Design atlas

> This atlas is optional inspiration. It is not a preset library, template catalogue, whitelist, or required starting point. Existing brand/template/user direction always wins. When direction is open, use entries as vocabulary: borrow, combine, reinterpret, or ignore them. Design for the content rather than copying fixed layouts, coordinates, fonts, or colors.

Read this only when visual direction is genuinely open and inspiration would materially help (see the branch routing in `SKILL.md`). Ground every choice in `references/design-foundations.md` — the atlas gives you names and vocabulary for directions; foundations tell you whether a direction actually serves the content.

## What the atlas answers

```text
What kind of visual language could fit this material?
What movements/styles can I borrow from?
What combinations could feel distinctive?
What visual vocabulary matches the audience?
```

It does **not** answer "which of the allowed styles should I use" — there is no allowed list. Named entries are vocabulary, not allowed values. The atlas is incomplete by design: a visual direction does not need to match any named entry. If the content or user direction suggests a better approach, invent or synthesize one instead.

## Priority order

```text
1. explicit user direction
2. supplied brand/template/reference deck
3. existing deck's language (for edits)
4. task/content requirements
5. optional design-atlas inspiration
```

The atlas is fifth. If the user says "use this company template," don't reach for "Art Deco Luxe." If the user says "change the price on slide 6," don't read this file at all. If the user says "surprise me, make it visually strong" with no template or brand, the atlas is appropriate.

## Dimensions, not presets

A visual direction is a combination of independent choices, not a single named preset:

```text
Visual language      the movement/aesthetic vocabulary (this file)
Typography            references/typography.md
Composition            references/compositions.md
Palette                references/color.md
Imagery                references/imagery.md
Information density    how much content per slide
Data language           references/data-design.md
Diagram language        references/diagrams.md
Motif                   references/motifs.md
```

Pick one answer per dimension and let them reinforce each other. Example:

```text
Visual language: editorial scientific
Typography: serif display + mono labels
Composition: asymmetric
Palette: warm neutral + one red
Imagery: archival documentary
Data: thin rules + annotated numbers
Diagram: engineering schematic
Motif: small coordinate labels
```

That is a design system, synthesized across dimensions — not a lookup into one named entry.

## Modernist / systematic

### Swiss International
**Character:** precise, rational, high-clarity.
**Useful when:** strategy, finance, technical explanation, consulting, institutional communication.
**Vocabulary:** asymmetric grid, grotesk type, strong alignment, limited palette, factual photography, disciplined whitespace.
**Combine with:** technical schematic, monochrome, editorial photography, oversized numerals.
**Watch:** sterile repetition — every slide becoming the same two-column grid.

### Bauhaus
**Character:** geometric, functional, primary-color confident.
**Useful when:** product/design-forward decks, education, anything wanting a "form follows function" statement.
**Vocabulary:** circles/triangles/squares as motifs, primary color blocks, geometric sans, grid discipline.
**Combine with:** Swiss grid, high-contrast monochrome, color-block.
**Watch:** becoming a literal shapes-collage instead of a disciplined system.

### De Stijl
**Character:** reduced to essential lines and primary colors, strict orthogonal structure.
**Useful when:** a deck wants extreme formal restraint and a strong grid statement.
**Vocabulary:** black grid lines, red/yellow/blue blocks, right angles only, asymmetric balance.
**Combine with:** Bauhaus, Swiss grid.
**Watch:** overuse becomes a gimmick rather than a system if applied to content-heavy slides.

### Constructivist
**Character:** bold, propagandistic energy, diagonal dynamism.
**Useful when:** a deck wants urgency and momentum — launches, calls to action.
**Vocabulary:** diagonal composition, bold sans, red/black palette, photomontage.
**Combine with:** typographic bold, high-contrast monochrome.
**Watch:** the political-poster association can read as heavy-handed for neutral business content.

### Modern corporate modernism
**Character:** confident, clean, safely contemporary.
**Useful when:** default choice for professional decks with no stronger direction specified.
**Vocabulary:** generous whitespace, rounded sans, soft shadows, restrained accent color.
**Combine with:** modern SaaS, soft UI.
**Watch:** becomes generic if it's the *only* decision made — pair with a real motif.

### Japanese minimalism
**Character:** quiet, precise, deliberate use of emptiness.
**Useful when:** premium, restrained, contemplative content.
**Vocabulary:** large negative space, thin rules, small precise type, asymmetric balance, muted palette.
**Combine with:** Nordic minimalism, quiet luxury.
**Watch:** can read as empty rather than intentional if hierarchy isn't sharp.

### Nordic minimalism
**Character:** warm-cool, functional, unpretentious.
**Useful when:** product, sustainability, design-conscious consumer content.
**Vocabulary:** light neutral palette, humanist sans, natural materials in imagery, soft edges.
**Combine with:** organic photography, soft data visualization.
**Watch:** can blur into generic "clean startup" without a specific motif.

### Monochrome minimal
**Character:** disciplined, confident, no distraction from content.
**Useful when:** content is strong enough to not need color to carry attention.
**Vocabulary:** single hue family, contrast from value/weight only, restrained type.
**Combine with:** Swiss, technical schematic, quiet luxury.
**Watch:** legibility risk if value contrast is too subtle.

### Museum / gallery catalogue
**Character:** curatorial, considered, object-focused.
**Useful when:** portfolio, cultural, design-history, or archival content.
**Vocabulary:** large image, small caption typography, generous margins, neutral background.
**Combine with:** editorial serif, documentary photography.
**Watch:** too much caption-scale text becomes illegible at presentation distance.

### Institutional modern
**Character:** credible, stable, slightly formal.
**Useful when:** government, education, healthcare, nonprofit communication.
**Vocabulary:** structured grid, conservative type pairing, muted accent, clear iconography.
**Combine with:** Swiss, annual-report editorial.
**Watch:** can tip into bureaucratic blandness without one real motif to anchor it.

## Editorial / print

### Editorial magazine
**Character:** confident storytelling, considered typography.
**Useful when:** narrative-led decks, brand storytelling, culture content.
**Vocabulary:** serif display, pull quotes, asymmetric grid, generous photography.
**Combine with:** documentary photography, warm palette.
**Watch:** long pull-quote text at slide scale can become unreadable — keep it short.

### Newspaper
**Character:** dense, information-forward, structured columns.
**Useful when:** news-style updates, data-dense reporting content.
**Vocabulary:** multi-column text, serif headlines, rules between sections, small captions.
**Combine with:** brutalist newspaper, data journalism data treatment.
**Watch:** column density that works in print rarely survives at slide scale — simplify.

### Brutalist newspaper
**Character:** raw, high-contrast, deliberately unpolished.
**Useful when:** a deck wants to signal directness and irreverence.
**Vocabulary:** heavy black rules, condensed headline type, stark black/white, asymmetric blocks.
**Combine with:** neo-brutalism, typographic bold.
**Watch:** can undercut credibility in conservative/institutional contexts.

### Luxury editorial
**Character:** refined, unhurried, high production value.
**Useful when:** premium brand, fashion-adjacent, high-end consumer content.
**Vocabulary:** serif display, wide margins, restrained palette, high-quality photography.
**Combine with:** quiet luxury, fashion editorial.
**Watch:** needs genuinely high-quality imagery — mediocre photos undercut the whole direction.

### Annual-report editorial
**Character:** credible, structured, data-literate.
**Useful when:** company reporting, financial storytelling.
**Vocabulary:** sectioned layout, data call-outs, restrained corporate palette, clean charts.
**Combine with:** Swiss, institutional modern.
**Watch:** every metric styled identically loses hierarchy between headline and supporting numbers.

### Bookish / literary
**Character:** warm, text-forward, unhurried reading pace.
**Useful when:** thoughtful, essay-like, reflective content.
**Vocabulary:** serif body text, cream/paper background, generous line height, restrained ornamentation.
**Combine with:** dark academia, museum catalogue.
**Watch:** slide medium is not built for long prose — keep text blocks short even in this direction.

### Dark academia
**Character:** moody, scholarly, atmospheric.
**Useful when:** research, history, institutional heritage content.
**Vocabulary:** deep muted palette, serif display, archival imagery, textured backgrounds.
**Combine with:** museum catalogue, risograph.
**Watch:** dark palettes need careful contrast checking for body text legibility.

### Risograph
**Character:** playful, textured, print-craft.
**Useful when:** creative, indie, community-facing content.
**Vocabulary:** slightly misregistered color layers, limited spot-color palette, grain texture.
**Combine with:** zine, screenprint, academic research content.
**Watch:** texture overuse can hurt legibility of fine text — keep body text clean even when decoration is textured.

### Screenprint
**Character:** bold, flat color, poster-like.
**Useful when:** event, music, culture, community content.
**Vocabulary:** flat color layers, bold display type, visible print imperfection.
**Combine with:** risograph, geometric poster.
**Watch:** flat color layering can reduce legible contrast if colors are chosen without a contrast check.

### Zine
**Character:** DIY, energetic, deliberately imperfect.
**Useful when:** community, grassroots, youth-oriented content.
**Vocabulary:** collage, mixed type scales, handmade elements, cut-and-paste layout.
**Combine with:** collage, cut-paper.
**Watch:** can read as unprofessional in formal business contexts — match to audience carefully.

### Independent publishing
**Character:** considered, small-press credibility.
**Useful when:** thoughtful creative or intellectual content wanting a non-corporate feel.
**Vocabulary:** restrained serif, generous whitespace, understated color, quality paper-stock feel.
**Combine with:** bookish/literary, museum catalogue.
**Watch:** needs strong content to justify the quiet presentation — it won't disguise a weak argument.

## Bold / graphic

### Neo-Brutalism
**Character:** raw, confident, intentionally unrefined.
**Useful when:** product/startup decks wanting to signal boldness and directness.
**Vocabulary:** thick borders, flat bold colors, chunky sans type, visible grid lines, hard shadows.
**Combine with:** typographic bold, high-contrast monochrome.
**Watch:** the current most-overused digital-design trend — apply only with a genuine reason, and restrain the palette.

### Typographic bold
**Character:** type as the primary graphic.
**Useful when:** a message is strong enough to need no supporting imagery.
**Vocabulary:** oversized display type, minimal imagery, strong weight contrast.
**Combine with:** neo-brutalism, single-family disciplined typography.
**Watch:** every slide at maximum type volume loses its own impact — save the biggest moves for the most important slides.

### Duotone
**Character:** graphic, cohesive, slightly retro-tech.
**Useful when:** photography-heavy decks wanting one strong cohesive color story.
**Vocabulary:** two-color-mapped imagery, matching type accent color.
**Combine with:** monochrome minimal, technical schematic.
**Watch:** needs source images with enough tonal range to duotone well.

### Memphis
**Character:** playful, geometric, deliberately clashing.
**Useful when:** youth brands, creative/design content wanting energy.
**Vocabulary:** squiggles, geometric confetti shapes, clashing color blocks, postmodern playfulness.
**Combine with:** color-block, geometric poster.
**Watch:** clashes badly with any content requiring institutional credibility.

### Maximalist collage
**Character:** dense, layered, maximal energy.
**Useful when:** culture/creative content wanting sensory richness.
**Vocabulary:** layered imagery, mixed type scales, overlapping elements, saturated color.
**Combine with:** collage, zine.
**Watch:** density works against the one-job-per-slide rule — use sparingly, usually on a single high-impact slide, not throughout.

### Pop-art influenced
**Character:** bold, graphic, culturally referential.
**Useful when:** consumer brand, culture, retrospective content.
**Vocabulary:** halftone texture, bold outline, saturated flat color, comic-adjacent type.
**Combine with:** color-block, retro Y2K.
**Watch:** strong cultural association — verify it fits the brand before committing a whole deck to it.

### Geometric poster
**Character:** graphic, confident, poster-scale impact.
**Useful when:** event, keynote, single-statement moments.
**Vocabulary:** large geometric shapes, bold flat color, minimal text.
**Combine with:** Bauhaus, screenprint.
**Watch:** works best on a small number of high-impact slides, not the whole deck's data slides.

### Color-block
**Character:** structured, confident, graphic.
**Useful when:** organizing distinct sections/categories visually.
**Vocabulary:** solid color fields as containers, clear boundaries, restrained type over color.
**Combine with:** Bauhaus, modern corporate modernism.
**Watch:** check text contrast against every block color used, not just the primary one.

### High-contrast monochrome
**Character:** stark, confident, dramatic.
**Useful when:** a deck wants maximum clarity and drama without color.
**Vocabulary:** pure black/white, bold type, strong photographic contrast.
**Combine with:** Swiss, brutalist newspaper.
**Watch:** no color means hierarchy must come entirely from scale/weight/position — verify it still reads at a glance.

## Digital / contemporary UI-derived

### Bento grid
**Character:** organized, dashboard-like, information-dense but tidy.
**Useful when:** product feature overviews, multi-item summaries.
**Vocabulary:** irregular grid of rounded cards, icon + label pattern, consistent card padding.
**Combine with:** modern SaaS, soft UI.
**Watch:** the most overused "AI deck" tell when applied to content that isn't actually a set of differently-weighted items — see the diagnostic list in `references/design-foundations.md`.

### Glassmorphism
**Character:** layered, translucent, contemporary UI feel.
**Useful when:** product/tech content wanting a sense of depth and modern software.
**Vocabulary:** frosted-glass panels, soft blur, subtle border highlight, layered depth.
**Combine with:** gradient mesh, dashboard/product UI.
**Watch:** applied to every slide it becomes a generic tell rather than a deliberate effect — reserve for slides where depth actually serves the content.

### Soft UI / restrained neumorphism
**Character:** tactile, soft, gentle depth.
**Useful when:** consumer product, wellness, approachable tech content.
**Vocabulary:** soft shadows both directions, muted palette, rounded corners, low contrast.
**Combine with:** modern SaaS, Nordic minimalism.
**Watch:** low contrast can hurt accessibility/legibility — verify text contrast independently of the aesthetic.

### Gradient mesh
**Character:** vivid, contemporary, energetic.
**Useful when:** consumer tech, creative tools, youth-oriented product content.
**Vocabulary:** soft multi-color gradient backgrounds, high-contrast type over them.
**Combine with:** glassmorphism, typographic bold.
**Watch:** the generic "AI tech" cyan-purple gradient is the most recognizable overused version of this — pick an unexpected gradient direction if using this at all.

### Clay-like / soft dimensional
**Character:** friendly, tactile, playful depth.
**Useful when:** consumer/product content wanting warmth and approachability.
**Vocabulary:** soft 3D-ish shapes, rounded volumetric icons, pastel palette.
**Combine with:** soft UI, Memphis.
**Watch:** can read as juvenile for enterprise/institutional audiences.

### Dashboard / product UI
**Character:** functional, data-literate, software-native.
**Useful when:** product demos, metrics-heavy operational content.
**Vocabulary:** card-based metric tiles, small data labels, consistent iconography, functional color coding.
**Combine with:** bento grid, modern SaaS.
**Watch:** every metric styled as an identical tile loses hierarchy — emphasize the metric that matters most.

### Modern SaaS
**Character:** clean, credible, contemporary business software feel.
**Useful when:** default direction for product/tech company decks without a stronger specified direction.
**Vocabulary:** generous whitespace, rounded sans, one confident accent color, soft shadows.
**Combine with:** modern corporate modernism, dashboard/product UI.
**Watch:** the most common baseline — pair with a real motif or it will look interchangeable with every other SaaS deck.

## Futurist / technical

### Architectural blueprint
**Character:** precise, technical, engineering-credible.
**Useful when:** technical/infrastructure/construction content, system explanations.
**Vocabulary:** thin white/cyan lines on dark navy, dimension marks, mono labels, grid paper feel.
**Combine with:** engineering schematic, Swiss.
**Watch:** legibility of thin lines at export/print resolution — keep line weight and label size generous enough.

### Engineering schematic
**Character:** precise, componentized, systems-literate.
**Useful when:** technical architecture, hardware, process explanation.
**Vocabulary:** clean line-art icons, grid-aligned connectors, mono annotation labels.
**Combine with:** blueprint, terminal/developer.
**Watch:** don't let schematic precision imply certainty the underlying system doesn't actually have.

### Cyberpunk outline
**Character:** high-energy, futuristic, edgy.
**Useful when:** genuinely appropriate for gaming/entertainment/edgy-tech content — rarely appropriate elsewhere.
**Vocabulary:** neon outline, dark background, glitch accents, angular type.
**Combine with:** HUD/interface, synthwave.
**Watch:** the brief's own example is explicit — a security-incident or enterprise-technical deck usually wants Swiss/schematic restraint, not this, despite the topic sounding "cyber."

### HUD / interface
**Character:** technical, real-time, data-overlay feel.
**Useful when:** simulation, monitoring, ops-center content.
**Vocabulary:** thin corner brackets, small live-data-style labels, crosshair/reticle motifs.
**Combine with:** cyberpunk outline, SOC.
**Watch:** decorative HUD elements with no actual data behind them read as empty gesture.

### Sci-fi holographic data
**Character:** futuristic, dimensional, high-tech.
**Useful when:** forward-looking product vision content, used sparingly.
**Vocabulary:** translucent layered panels, glowing thin lines, dark background.
**Combine with:** glassmorphism, gradient mesh.
**Watch:** easily tips into science-fiction pastiche that undercuts credibility for real technical claims.

### Isometric technical
**Character:** precise, dimensional, systems-literate.
**Useful when:** architecture diagrams, physical/infrastructure explanation.
**Vocabulary:** isometric projection illustrations, consistent light source, restrained palette.
**Combine with:** engineering schematic, blueprint.
**Watch:** isometric illustration is labor-intensive to get right — a poorly executed isometric diagram is worse than a flat one.

### Wireframe / CAD
**Character:** precise, pre-production, technical draft feel.
**Useful when:** product design, engineering, architecture content.
**Vocabulary:** line-only geometry, mono dimension labels, monochrome.
**Combine with:** blueprint, engineering schematic.
**Watch:** works best when the content is genuinely about structure/form, not as decoration on unrelated slides.

### Scientific instrumentation
**Character:** precise, empirical, credible.
**Useful when:** research, lab, measurement-heavy content.
**Vocabulary:** axis-tick motifs, mono data labels, restrained palette, plotted-data feel.
**Combine with:** engineering schematic, editorial scientific (see combination examples).
**Watch:** don't let instrument aesthetics imply precision the actual data doesn't have.

### Terminal / developer
**Character:** technical, direct, developer-native.
**Useful when:** developer tools, technical documentation-style content.
**Vocabulary:** monospace throughout, dark background, minimal color, prompt/cursor motifs.
**Combine with:** engineering schematic, security operations.
**Watch:** monospace-only body text hurts reading speed for longer passages — reserve mono for labels/code, use a readable sans for body.

### Security operations / SOC
**Character:** alert, monitored, high-stakes technical.
**Useful when:** security incident reports, monitoring/ops content.
**Vocabulary:** dark background, status-color coding (amber/red for severity), mono metadata, grid of status tiles.
**Combine with:** terminal/developer, HUD.
**Watch:** status colors must be used consistently and sparingly or they lose their alerting function.

**Vocabulary:** chrome/gradient text, bubble shapes, saturated color, glossy highlights.

**Vocabulary:** pastel pink/cyan gradients, classical statuary/grid motifs, glitch accents.
**Combine with:** synthwave, retro Y2K.

### Synthwave / neon Miami

**Useful when:** entertainment, music, nightlife-adjacent content.
**Vocabulary:** magenta/cyan neon on dark, grid-horizon motif, chrome type.
**Combine with:** retro Y2K, cyberpunk outline.
**Watch:** same narrow appropriate-use window as retro Y2K.

### Art Deco
**Character:** glamorous, geometric, confident luxury.
**Useful when:** hospitality, events, heritage-brand content.
**Vocabulary:** symmetrical geometric ornament, metallic accent, elegant display serif.
**Combine with:** luxury editorial, quiet luxury.
**Watch:** ornament can overwhelm data-heavy content — reserve for cover/section slides.

### Mid-century modern
**Character:** optimistic, warm, confidently simple.
**Useful when:** heritage brand storytelling, warm consumer content.
**Vocabulary:** organic geometric shapes, warm muted palette, clean sans type.
**Combine with:** earth-tone natural, editorial magazine.
**Watch:** can read as dated pastiche if not paired with genuinely contemporary layout logic.

### 70s editorial
**Character:** warm, confident, analog.
**Useful when:** culture/heritage content wanting warmth over precision.
**Vocabulary:** warm earth palette, rounded display type, halftone texture.
**Combine with:** earth-tone natural, mid-century modern.
**Watch:** typography choices here can hurt legibility if pushed too far into pure pastiche.

### 80s geometric
**Character:** bold, confident, graphic.

### 90s rave
**Character:** energetic, chaotic-on-purpose, youth culture.
**Useful when:** music/event/youth culture content specifically.
**Vocabulary:** clashing saturated color, distorted type, scan-line/glitch texture.
**Combine with:** vaporwave, zine.

### Early-web / webcore
**Character:** nostalgic, DIY-digital, deliberately unpolished.
**Useful when:** internet-culture, retro-tech-nostalgia content.
**Vocabulary:** pixel accents, basic system fonts, visible-grid naivety, low-fi color.
**Combine with:** terminal/developer, zine.
**Watch:** narrow genre fit — a deliberate reference, not a default.

## Organic / atmospheric

**Vocabulary:** hand-drawn accents, organic shapes, warm neutral palette, textured backgrounds.
**Combine with:** botanical, earth-tone natural.

### Dark forest

**Vocabulary:** deep green palette, organic photography, restrained gold/cream accent.
**Combine with:** botanical, biotech organic-tech.

### Botanical
**Character:** natural, calm, growth-oriented.
**Useful when:** wellness, sustainability, natural-product content.
**Vocabulary:** plant photography/illustration, green/cream palette, organic line work.
**Combine with:** Nordic minimalism, earth-tone natural.

### Earth-tone natural

**Vocabulary:** terracotta/sand/olive palette, natural texture, humanist type.

### Liquid organic

**Useful when:** beauty, wellness, contemporary consumer content.
**Vocabulary:** blob/fluid shapes, soft gradients, gentle motion-suggesting curves.
**Combine with:** clay-like, gradient mesh.

### Biotech organic-tech
**Character:** precise but alive — science meeting nature.
**Useful when:** biotech, healthtech, life-sciences content.
**Vocabulary:** molecular/cellular pattern motifs, clinical-clean palette with one organic accent, precise sans type.
**Combine with:** scientific instrumentation, dark forest.

### Documentary photographic
**Character:** authentic, grounded, credible.
**Useful when:** impact, nonprofit, real-world proof content.
**Vocabulary:** unstaged photography, minimal graphic overlay, honest color grading.
**Combine with:** editorial magazine, earth-tone natural.
**Watch:** image quality must be genuinely good — a low-quality "authentic" photo just reads as low quality.

### Soft humanist
**Character:** warm, approachable, people-first.
**Useful when:** HR, culture, people-focused organizational content.
**Vocabulary:** humanist sans, warm neutral palette, real (not stock-generic) photography of people.
**Combine with:** Nordic minimalism, modern SaaS.
**Watch:** generic stock photography of people undercuts the "authentic" intent entirely.

## Artistic / expressive

### Stained-glass inspired
**Character:** vivid, segmented, luminous.
**Useful when:** cultural/heritage/artistic content wanting a distinctive graphic identity.
**Vocabulary:** segmented color panels, bold outlines, jewel-tone palette.
**Combine with:** collage, art deco.
**Watch:** a strong, unusual reference — verify it fits the content before committing a whole deck to it.

### Collage
**Character:** layered, eclectic, expressive.
**Useful when:** creative, culture, brand-story content.
**Vocabulary:** layered cutouts, mixed image sources, varied type scale.
**Combine with:** maximalist collage, zine, cut-paper.
**Watch:** needs a unifying element (consistent palette or one repeated shape) or it reads as chaotic rather than expressive.

### Cut-paper
**Character:** tactile, crafted, dimensional.
**Useful when:** creative, children's/educational, handmade-brand content.
**Vocabulary:** layered flat shapes with drop shadows, bold flat color, playful composition.
**Combine with:** collage, Memphis.
**Watch:** works best when genuinely illustrated for the deck, not approximated with generic clip art.

### Riso (as an artistic register, distinct from print-production use)
**Character:** textured, artful, limited-palette.
**Useful when:** creative/independent content wanting handmade credibility.
**Vocabulary:** limited spot colors, visible grain, slight misregistration.
**Combine with:** risograph (print register), zine.
**Watch:** duplicate of the print-production risograph entry in intent — use one register consistently per deck, not both.

### Mixed-media
**Character:** eclectic, textured, expressive.
**Useful when:** creative portfolios, brand storytelling with varied source material.
**Vocabulary:** combined photography/illustration/texture, varied but coordinated palette.
**Combine with:** collage, documentary photographic.
**Watch:** coordination is what separates this from visual noise — pick one palette to unify otherwise-varied sources.

### Abstract geometry
**Character:** confident, modern, non-literal.
**Useful when:** content without an obvious literal visual (abstract concepts, financial/strategic content).
**Vocabulary:** non-representational shapes, confident color blocks, geometric rhythm.
**Combine with:** Bauhaus, color-block.
**Watch:** purely decorative abstract shapes with no relation to content read as filler — tie shape/rhythm to the actual argument where possible.

### Gradient art
**Character:** contemporary, vivid, atmospheric.
**Useful when:** used deliberately and sparingly for mood-setting moments.
**Vocabulary:** painterly gradients, soft color transitions, minimal competing elements.
**Combine with:** gradient mesh, liquid organic.
**Watch:** the single most overused "AI deck" background — use an unexpected palette and restrained frequency if used at all.

### Experimental typography
**Character:** bold, distinctive, type-as-art.
**Useful when:** a deck wants typography itself to be the memorable visual signature.
**Vocabulary:** variable weight/scale within one word, unconventional kerning/layout, type as image.
**Combine with:** typographic bold, editorial asymmetric composition.
**Watch:** legibility must survive the experimentation — a headline nobody can read fast has failed regardless of how striking it looks.
