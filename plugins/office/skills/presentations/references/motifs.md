# Motifs

A motif is a recurring gesture that gives a deck identity — not a template, and not mandatory. Choose zero or one primary motif for most decks; it supports identity, it doesn't need to appear loudly on every single slide, and an existing brand motif always wins over inventing a new one.

## Catalogue

```text
hairline grid          faint grid lines visible behind/around content
edge label              small label fixed to a slide edge (e.g. section name)
oversized numeral        a large number used as a graphic element, not just data
section counter          running count like "03 / 12" marking position in the deck
single accent rule       one thin colored line used consistently as a divider
corner bracket            small bracket marks at a frame's corners, camera/technical feel
technical annotation      callout lines and labels in a schematic style
coordinate ticks          small tick marks suggesting a ruler/axis, used decoratively
cropped circle            a circle deliberately cropped by the frame edge
offset frame              a border offset from its content rather than tight around it
floating pill label        a small rounded label detached from its anchor content
small mono metadata        tiny monospace text used for timestamps/IDs/tags
image border treatment     a consistent border/frame style applied to every image
full-width baseline         a horizontal rule spanning the full slide width
vertical spine              a vertical line or band anchoring one edge of every slide
diagonal slice              an angled dividing line between two regions
underlined keyword           a single emphasized word underlined for attention
highlight block               a colored block behind a key phrase
side rail                      a narrow vertical strip holding recurring metadata
micro-grid                     a small repeating grid pattern used as texture
gradient glow                  a soft radial glow behind a focal element
paper texture                  a subtle paper/grain texture on the background
riso offset                    slightly misaligned color layers, print-inspired
duotone wash                    a consistent two-color tint applied across imagery
photo cutout                    subjects isolated from photo backgrounds throughout
caption system                  a consistent small-caption style under every figure
chapter tabs                    tab-like markers indicating deck sections
progress marker                  a visual indicator of position within a sequence
connected nodes                  small dot-and-line connectors used as a recurring graphic
thin arrow language               a consistent arrow style used for all directional cues
```

## How to use one

Pick a motif that fits the content and the chosen visual language (`references/design-atlas.md`), not the one that looks most striking in isolation — a hairline grid suits a technical/Swiss direction, a paper texture suits an editorial/archival one. Apply it with enough consistency that a reader would notice its absence, but not so mechanically that it appears identically positioned on every slide regardless of that slide's content. A motif that never varies its execution starts to look like a template stamp rather than a design decision.
